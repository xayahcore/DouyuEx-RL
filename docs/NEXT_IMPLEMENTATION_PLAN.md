## 二、 NEXT 目标架构拓扑设计

NEXT 彻底废弃单文件与全局变量混合的原始结构，采用 **现代 5 层高内聚、单向数据流体系**：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        NEXT 5 层工程解耦拓扑                           │
├────────────────────────────────────────────────────────────────────────┤
│ 1. Core Intercept Layer (执行时机: document-start)                     │
│    ├── QualityLock (原画秒开强锁, 掐断低清预载, 12s保护窗)            │
│    ├── RankEngine (主上下文 WebSocket STT 协议挂钩与亲密度还原)         │
│    └── P2PBlocker (W3C 规范假原型阻断 WebRTC 上传, 消除报错)           │
├────────────────────────────────────────────────────────────────────────┤
│ 2. DouyuClient Gateway (统一 API 与安全中枢)                          │
│    ├── 凭据管家 (自动探测/刷新 ccn, post-csrfToken, dy-device-id)       │
│    ├── 请求调度器 (统一封装 fetch / GM_xmlhttpRequest，内置防风控限频) │
│    └── 类型化业务接口 (room, user, backpack, routine, radar)            │
├────────────────────────────────────────────────────────────────────────┤
│ 3. Reactive State Store (响应式状态中枢)                              │
│    ├── roomStore (房间号纯数字归一化, 主播名, 开播状态)               │
│    ├── userStore (登录态, UID, 真实佩戴粉丝牌动态识别)                 │
│    ├── backpackStore (背包道具资产字典与有效期映射)                    │
│    └── configStore (强语义配置，搭载 DataMigrator 兼容老版本 44 个键)   │
├────────────────────────────────────────────────────────────────────────┤
│ 4. MIUIX UI Component Engine (拟态视图组件层)                          │
│    ├── Design Tokens (纯 CSS Variables, 样式文件瘦身 70%)              │
│    ├── IconSprite (集中式 SVG 矢量字典, 消除 100KB+ 模板内联字符串)    │
│    ├── DockController (二级 Dock 常驻装配与 180ms 隐形连桥)            │
│    └── ModalWindowManager (370px 齐平三维模态窗与 540px 礼物大选择器)  │
├────────────────────────────────────────────────────────────────────────┤
│ 5. Decoupled Feature Modules (100% 独立业务能力集)                     │
│    ├── module-economy (背包送礼, 自动续牌, 5大签到闭环, 自动钓鱼)       │
│    ├── module-danmaku (小尾巴, 收藏, 回复, 查弹幕, 净化过滤, +1/作者卡)│
│    ├── module-media (增强画中画小窗发言, 同屏多开, 滤镜比例, 录制导出) │
│    ├── module-radar (全站抽奖雷达, 主播硬件配置探测)                  │
│    └── module-passport (导航栏多账号无感切换管道)                     │
└────────────────────────────────────────────────────────────────────────┘
```

## 四、 逐阶段详细工程施工清单

### Phase 1: 核心拦截底座与统一网关
**目标**：建立零污染的编译环境、移植高可靠的核心拦截层，封装标准统一网络通信网关。

1. **工程脚手架与目录重组**：
   - 建立规范的模块化工程树：`src/core/`、`src/api/`、`src/store/`、`src/ui/`、`src/modules/`；
   - 更新 `build.js`，支持按照拓扑依赖图自动解析打包，集成 Node.js 原生 V8 AST 校验。
2. **底层核心拦截层模块化 (`src/core/`)**：
   - `src/core/quality.js`：继承首流原画截杀逻辑，封装为 `QualityInterceptor`，12 秒状态机保护窗 + 预载流掐断；
   - `src/core/rank_engine.js`：封装为 `RankEngine`，挂钩 WebSocket STT 协议解析，注入亲密度与贡献值；
   - `src/core/p2p_blocker.js`：封装符合 W3C 标准的假 `RTCPeerConnection` 原型对象，优雅阻断 WebRTC 上传。
3. **统一网络与安全网关 (`src/api/client.js`)**：
   - 封装单例 `douyuClient`，统一底层 `fetch` 与 `GM_xmlhttpRequest`；
   - **自动凭据注入中枢**：
     - 自动检测并唤醒 Cookie `ccn`（缺失时请求 `/wgapi/livenc/liveweb/csrfApi/getCsrfCookie`）；
     - 自动维护 `post-csrfToken`；
     - 自动携带当前房间纯数字 `rid` 与 `dy-device-id`；
   - **防御机制**：内置统一请求重试机制（支持指定重试次数与退避延迟）与并发频率控制。
4. **子领域 API 封装**：
   - `src/api/room.js`：房间配置 (`/betard/{rid}`)、在播礼物列表 (`RoomApi/room/{rid}`)；
   - `src/api/user.js`：背包道具 (`prop/backpack/web/v5`)、背包赠送、勋章列表 (`getFansBadgeList`)、关注/取关 (`follow/add`, `follow/rm`)；
   - `src/api/routine.js`：客户端签到、鱼吧打卡与补签、星推榜单与任务上报 (`anchorstardiscover`)、自动钓鱼 (`fishing/homePage`, `fishing/reelIn`)；
   - `src/api/radar.js`：全站抽奖列表、主播硬件推流环境快照 (`member/cp`)。

### Phase 2: 响应式状态机与配置迁移
**目标**：消灭单字母全局变量（`B`, `m`, `w()` 等），建立单例状态管理，并提供老版本配置无缝迁移器。

1. **状态机核心 (`src/store/index.js`)**：
   - 实现轻量发布/订阅事件中枢（Pub/Sub EventBus）；
2. **领域状态切片**：
   - `roomStore`：数字房间号 (`roomId`)、主播名、真实开播状态、原画锁定状态；
   - `userStore`：登录态、UID、昵称、当前佩戴真实粉丝牌名称（动态感知，0 硬编码）；
   - `backpackStore`：背包道具映射字典、道具存量、过期时间戳；
3. **配置中枢与数据迁移器 (`src/store/configStore.js`)**：
   - 建立结构化配置定义（强语义命名，如 `danmakuTail.enabled`, `autoSign.options`）；
   - **老数据迁移器 (`DataMigrator`)**：
     - 首次启动自动扫描读取旧版 44 个 `ExSave_*` 键；
     - 自动迁移弹幕小尾巴文本、关键词自动回复列表、签到勾选项、投票主题等；
     - 确保老用户无感平滑过渡，个性化配置零丢失。

---

### Phase 3: MIUIX 拟态组件系统
**目标**：将 100KB+ 杂乱样式瘦身 70%，建立标准矢量图标库与统一样式系统。

1. **MIUIX 设计令牌 (`src/ui/tokens.css`)**：
   - 建立纯 CSS 变量集（毛玻璃 `--miuix-blur: blur(28px)`、拟态背景、品牌橙 `#ff5d23`、深色文字与边框）；
   - 极细 4px 滚动条、全域广告类名屏蔽池；
2. **矢量图标库 (`src/ui/icons.js`)**：
   - 集中收敛全站图标 SVG Path 为单例字典，杜绝在 DOM 里硬拼成百行字符串；
3. **容器与悬浮控制器 (`src/ui/dock.js`)**：
   - 挂载 Level 2 Dock 工具栏，实现 150% 等比适配；
   - 18px 隐形连桥与 180ms 防抖关卡，Dock 磁吸高亮胶囊；
4. **模态窗基类 (`src/ui/modal_base.js`)**：
   - 统一 380×370px 齐平三维控制台框架；
   - 粘性吸顶 Header（带右侧强优先级 `×` 按钮，彻底消灭右侧漏缝）。
