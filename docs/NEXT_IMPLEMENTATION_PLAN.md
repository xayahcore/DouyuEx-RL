## 一、 顶层架构设计哲学

面对原作者积累 6 年、充斥着单字母混淆与字符串拼接的几万行老代码，如果我们继续用传统方式一行行重写，不仅代码量会膨胀到数千行，而且极易出现新的 Bug。

为了做到 **“代码行数减半、运行开销归零、维护极度轻松、交互 100% 保真”**，NEXT 确立四大工程解法：

### 1. 怎样少写代码？——「声明式 MIUIX 组件工厂」
- **彻底消灭 innerHTML 字符串拼接**：老代码中成千上万行 `<div class="card">...</div>` 重复拼接是代码冗余的罪魁祸首。
- **内置轻量 DOM 构造工厂与组件库**：
  在 `src/ui/miuix.js` 中内置原子级组件生成器：
  ```javascript
  MIUIX.Panel({ id, title, width, height, body })
  MIUIX.Card({ title, subtitle, items })
  MIUIX.Switch({ id, label, key, checked, onChange })
  MIUIX.Accordion({ id, title, badges, content })
  MIUIX.Dialog({ title, message, onConfirm, onCancel, prompt: true }) // 统一替换旧版所有 alert/prompt 弹窗
  MIUIX.Toast(message, type) // 统一通知气泡
  ```
  原本需要写 150 行 HTML 字符串的手风琴子面板（如进场欢迎、自动回复），在 NEXT 中只需 **15 行声明式代码** 即可装配完成！

### 2. 怎样降低开销？——「零轮询 (Zero-Polling) 与 WeakMap 弱引用」
- **坚决剔除一切盲目轮询**：
  老代码满屏皆是 `setInterval(fn, 1000)` 盲目检查 DOM 是否生成，极度消耗 CPU 且容易造成主线程卡顿。NEXT 全面采用 **精确事件监听 + MutationObserver 靶向观察**，DOM 挂载即响应，渲染完成立即销毁观察器；
- **内存防泄漏**：所有 DOM 与临时上下文关联一律采用 `WeakMap`，页面换房或小窗销毁时，V8 引擎自动垃圾回收 (GC)，挂机 24 小时内存曲线水平平稳。

### 3. 怎样保证状态一致？——「单行数据双向绑定器 (Data Binder)」
- 老代码每个面板都需要手动读取 `localStorage.getItem`，然后手动赋值给 input，再手动绑定 `change` 写回，造成了上百处重复代码且极易读出脏数据。
- NEXT 的响应式 Store 提供统一绑定器：
  ```javascript
  store.bindCheckbox('#vote__repeat', 'vote.repeatEnabled');
  store.bindInput('#danmaku_tail_txt', 'danmaku.tailContent');
  ```
  仅需一行代码，自动处理“初始化回显 ➔ 用户变更感知 ➔ 本地持久化 ➔ 跨组件事件通知”，杜绝任何冗余。

### 4. 怎样统一网络与凭据？——「单例 DouyuClient SDK」
- 老代码每个函数各自用 `fetch` 或 `GM_xmlhttpRequest` 乱拼 URL，凭据一会儿传 `w()`，一会儿传 `acf_auth`，一会儿又漏了 `ccn`。
- NEXT 统一收敛至 `client`：所有请求统一自动注入 `ccn`、`post-csrfToken`、`dy-device-id`，自带风控退避重试，业务层只写一行语义化调用（如 `client.follow(rid)`、`client.reelIn(rid)`）。

## 三、 内置 MIUIX UI 风格库原子设计规范

所有 UI 渲染（从 Dock、三级模态控制台、手风琴子菜单，到左下角的提示/输入弹窗）**统一通过 `MIUIX` 工厂 API 构造，严禁在业务代码中出现拼接 HTML 字符串**。

### 3.1 原子组件工厂清单 (`src/ui/miuix.js`)
1. **`MIUIX.Panel(options)`**：
   - 生成 380×370px 标准三级模态视窗；
   - 自动装配粘性毛玻璃吸顶 Header、标题文本、副标提示与右侧贴边纯净 `×` 强优先级关闭按钮。
2. **`MIUIX.Accordion(options)`**：
   - 专为 `livetool` 与复杂设置打造的伸缩手风琴组件；
   - 支持主标题点击展开/折叠对应子配置面板，右侧支持配置辅助操作按钮（如【面板】、【导入】、【导出】）；
   - 自动处理多项互斥或联动展开，彻底替换原版脆弱的 class style 显隐切换。
3. **`MIUIX.Card(options)`**：
   - 纯净四级拟态卡片容器，统一外边距、内衬 Padding 与微发光圆角边框。
4. **`MIUIX.Switch(options)`**：
   - 标准物理手感滑动开关，支持传入 `storeKey` 一键双向绑定状态。
5. **`MIUIX.InputRow(options)` / `MIUIX.SelectRow(options)`**：
   - 规范标签与输入框/下拉菜单左右排列布局，内置数字校验与聚焦高亮。
6. **`MIUIX.Dialog(options)`（彻底替代老旧的第三方 postbird 与原生 alert/prompt）**：
   - 在页面中央呼出统一 MIUIX 毛玻璃质感模态对话框；
   - 支持 `alert`（纯提示）、`confirm`（双按钮确认）与 `prompt`（带输入框交互）；
   - 彻底消灭原作者遗留的旧版外包弹窗样式。
7. **`MIUIX.Toast(message, type)`**：
   - 屏幕上方滑动浮现的纯文字状态反馈胶囊（info / success / error），自动 3 秒渐隐销毁。

## 四、 从零重构完整实施流水线

### Phase 1: 基础设施三剑客
**目标**：构建零污染编译底座，移植已验证的核心拦截层，封装统一通信 SDK。

1. **工程结构建立 (`DYEXRL-NEXT` 分支)**：
   - 清理所有老式杂乱脚本，建立全新的模块化文件树；
   - 优化 `build.js`，按照拓扑依赖顺畅拼接，挂载 Node.js 原生 V8 AST 语法核验。
2. **核心底层拦截移植 (`src/core/`)**：
   - `quality.js`：保留经生产验证的 12 秒状态机、预载流掐断与 `/betard/` 画质强锁，重构为纯净 ES6 结构；
   - `rank_engine.js`：提取 WebSocket STT 协议双重转义解析器，重构为响应式贡献榜还原模块；
   - `p2p_blocker.js`：封装标准 W3C 假原型阻断 WebRTC P2P 上传。
3. **统一网络与凭据网关 (`src/api/client.js`)**：
   - 封装单例 `douyuClient`，提供统一的 `get` 与 `post` 方法；
   - 自动提取并管理 `ccn` Cookie 与 `post-csrfToken`；
   - 内置请求重试状态机与频控延时调度，业务代码告别手拼 URL。
4. **子领域 API 协议定义 (`src/api/`)**：
   - `room.js`：房间信息、专属礼物与通用大盘礼物；
   - `user.js`：用户背包资产、粉丝勋章、关注与安全取关接口；
   - `routine.js`：签到链路、星推榜单与任务上报、**自动钓鱼 `homePage`/`reelIn` 接口**；
   - `radar.js`：全站抽奖监控广播、主播硬件推流快照接口。

### Phase 2: 响应式状态机与配置迁移
**目标**：彻底消除单字母天书，建立全局响应式数据流，确保老用户无感升级。

1. **状态机核心 (`src/store/index.js`)**：
   - 搭建轻量 Pub/Sub EventBus 事件中枢；
   - 封装 `bindInput`、`bindCheckbox` 单行绑定能力。
2. **领域状态切片 (`src/store/`)**：
   - `roomStore.js`：纯数字房间号归一化、主播名、开播状态；
   - `userStore.js`：登录状态、UID、当前佩戴真实粉丝牌名称（动态嗅探，杜绝写死“幻神”）；
   - `backpackStore.js`：背包资产字典、道具有效期限。
3. **老数据迁移器 (`src/store/migrator.js`)**：
   - 首次初始化时，自动读取老版本 44 个 `ExSave_*` 键；
   - 将小尾巴预设、自动回复规则、签到勾选记忆无缝迁移至新版语义化配置中，老用户升级设置零丢失。

### Phase 3: 内置 MIUIX 拟态组件库与通用对话框引擎
**目标**：将 100KB+ 杂乱样式瘦身 70%，建立标准矢量图标字典与统一组件工厂。

1. **设计令牌与全局样式 (`src/ui/tokens.css`)**：

   - 极细 4px 滚动条、全站商业广告与浮动挂件屏蔽池。
2. **矢量图标中心 (`src/ui/icons.js`)**：
   - 集中式 SVG Path 单例字典（sign, fans, tool, live, bloop, lottery, player, update 等），消灭全部内联重复字符串。
3. **MIUIX 原子组件库实现 (`src/ui/miuix.js`)**：
   - 编写 `Panel`、`Card`、`Accordion`、`Switch`、`Dialog`、`Toast` 等核心工厂方法。
4. **Dock 栏装配与交互守卫 (`src/ui/dock.js`)**：
   - 纯组件化挂载 10 个功能图标；
   - 18px 隐形悬浮连桥、180ms 防误触延时、磁吸胶囊高亮指示器。
