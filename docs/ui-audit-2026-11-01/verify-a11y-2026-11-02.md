## 1. 复算口径

### 1.1 合成底（按 `docs/ui-audit-2026-11-01/PLAN.md:48` 的 D1 定版取值）

| 模式 | 叠层顺序 | 有效底 | 依据 |

| 白天态 | 托盘 `rgba(255,255,255,0.34)` → 白片 `rgba(255,255,255,0.42)` | `1−(1−0.34)(1−0.42) = 0.617` | `PLAN.md:48`、`UI-UX-REVIEW.md:156` |
| 黑夜态 | 外壳 `rgba(16,20,26,0.18)` + `brightness(0.45)` → 卡片 `rgba(16,20,26,0.14)` | `1−(1−0.18)(1−0.14) = 0.295` | `ExPanel.css:3537-3551`、`UI-UX-REVIEW.md:96` |

令牌真源：`ExPanel.css:6-76`（白天）、`ExPanel.css:3536-3551`（黑夜，`html:is([data-dx-theme="dark"], …)` 块）。

### 1.2 计算式

`ratio = (L1+0.05)/(L2+0.05)`，`L` 为 WCAG 2.1 相对亮度；`rgba` 前景先按 alpha 合成到底色，再算对比。
取 5 个视频帧 `#000000 / #101418 / #6b7280 / #d8dee6 / #ffffff` 的**最坏值**：

| 模式 | 最坏帧 | 合成底实测 |
|---|---|---|
| 白天态（暗墨） | 纯黑 `#000000` | **`#9d9d9d`**（暗场 `#101418` → `#a4a5a7`） |
| 黑夜态（白墨） | 纯白 `#ffffff` | **`#565759`**（暗场 `#101418` → `#0a0c0f`） |

阈值：正文/说明文字 **4.5:1**，图形/指示器 **3.0:1**（WCAG 1.4.3 / 1.4.11）。
