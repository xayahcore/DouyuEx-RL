**由此得到四条必须在 S0.5 之前就定下的事**

1. **body 有两种来源**：7 个面板模板自带 `__body`，2 个（签到 / 直播间工具）靠 `ExPanel.js:623-639` 注入并**把已有子节点整包搬走**。同一个类，两种生成路径 —— 这就是"嵌套层"最容易出事的地方（搬节点会打断事件委托与 focus）。
2. **卡片有五类**：`.fans-panel__card`（5 个面板共用）/ `.popup-panel__card` / 动态生成 / 无卡片 / 死类名。ExUI 的 `.ui-card` 要一次覆盖这五类，不能只按签到面板的写法。
3. **子项有四套**：`.sign-option-item`（4 个面板）/ `.bloop__param_item` / `.livetool__cell` / 无子项层。其中 `.livetool` 的**抽屉与按钮是兄弟**，属于结构性特例：迁移时必须先决定"抽屉挂哪儿"，否则弹幕派发与开关联动会断。
4. **顺序依赖**：`.livetool` 的 5 个子包靠 `insertBefore` 到首子节点，迁移后若改成 append，视觉顺序会整体反转 —— 迁移判据里要显式加一条「子项顺序与基线一致」。

> 以上每条都会在 S0.5 变成一张"关层前 / 关层后"的对照图；S0.5 的结论表按这 9 个面板逐个填，而不是只做一个样板。

### 1.6 测量环境的一个坑（2026-11-01 查清，影响所有绝对计数）

| 事实 | 证据 |
|---|---|
| **ego profile 里常驻一份旧版插件** | 不注入任何东西、只打开房间页：`.ex-panel` ×1 · `.ex-icon` ×1 · `.ex-panel__wrap` ×1（`GM_info` 为 undefined，说明是早前会话装进去的那份） |
| 再注入本构建 → 变成两份 | 面板 ×2 · 精灵球 ×2 · `.ex-panel__wrap > div` 16 枚（8+8，其中 8 枚全零尺寸 —— 就是 §1.5 那条"第二份零尺寸 wrap"） |
| 因此**绝对计数会偏大** | "16 枚磁贴""两个精灵球"都是这么来的，不是产品 bug |
| **差分结论不受影响** | 基线/迁移后两次采集在同一环境下进行，第二实例是常量；签到的 0 像素差、8/8 结构化 PASS 依然成立 |
| 已加的防护 | `tools/ui-snap.mjs` 启动时打印 `[env]`（wraps / ours / icons / a11yTiles），并用 `data-dx-a11y` 认自己的磁贴；下次环境异常会当场显示 |

**两个"尾巴"的结案**

| # | 原判 | 实测结论 |
|---|---|---|
| 1 | 焦点环 1px ≠ 规格 2px | **不是缺陷**。真实键盘走位（点磁贴 → Shift+Tab → Tab）下实测 `outline: 2px solid rgb(0,106,255)`、`offset: 2px`、选择器 `.ex-panel__wrap > div:focus-visible` 命中。之前的 1px 是探针在非 `:focus-visible` 状态下读的假读数 |
| 2 | 精灵球被插成两份 | **不是产品 bug**，是上面那份常驻旧版留下的副本（它没有新语义，因为它是旧构建）。本构建的精灵球语义齐全 |

### 4.5 比对还原体系（用 ego 浏览器，不用别的浏览器）

> 你指定：**以后 agent 自己操作一律用 ego-browser（ego lite）** —— 它是为 agent 生的浏览器，本会话有完全权限。下面的采集器就按 ego 的 API 写，不再用 bsk 去驱动你的 Edge。

**ego 的调用形态（已实测可用：v2.2.0 / windows）**

```bash
ego-browser nodejs <<'EOF'
const task = await taskSpace("dyex-ui-migration-s0");
const page = task.page("p1");
await page.goto("https://www.douyu.com/9999");
await page.waitForFunction(() => !!document.querySelector(".ex-panel__wrap"));
const snap = await page.evaluate(() => {
  // 在页面内采集：每个可见元素的路径 + rect + 样式子集
  return "…";
});
console.log(JSON.stringify(snap));
EOF
```

要点（照 ego 指南）：脚本跑在 Node 侧，DOM 只能进 `page.evaluate()`；截图用 `page.screenshot({ path })`；等状态用 `waitForSelector` / `waitForFunction`，不要定时延；每轮写**新的** `round-XX.mjs`，不重放旧轮；结束时 `finish()` 只保留要留的 Page。

**工具三件套（S0-5 建，落在 `tools/`）**

| 工具 | 作用 | 用法 |
|---|---|---|
| `tools/ui-snap.mjs` | 采集器（ego 脚本）：开真房间 → 逐面板展开 → `page.evaluate` 导出**结构化快照 JSON**（元素路径、rect、background/border/radius/font-size/line-height/color/box-shadow/z-index） | `ego-browser nodejs < tools/ui-snap.mjs -- --panel all --out baseline` |
| `tools/ui-diff.mjs` | 比对器（纯 Node）：两份快照按元素路径配对 → 几何 / 颜色 / 字体三类差异表 + 元素增删清单 + 退出码 | `node tools/ui-diff.mjs baseline after --panel sign` |
| 截图层 | 同一个 ego 会话里 `page.screenshot` 出全屏 + 面板裁切，逐像素 diff | 与快照同轮产出 |

**"基本大差不差"的可核验阈值**

| 类别 | 阈值 |
|---|---|
| 几何 | 配对元素 x/y/w/h 差 **≤1px**；元素数量变化必须逐条列明理由 |
| 颜色 | 背景/边框/文字色每通道 **≤2/255** |
| 字体 | 字号、行高、字重 **必须完全相等** |
| 像素 | 极差 **≤1 灰阶**；差异像素占比 <0.5% 且全部落在抗锯齿边缘 |
| 顺序 | 子项顺序与基线**完全一致**（专治直播间工具那种「插到首子」的写法） |
| 功能 | S0-2 清单 100% 勾选 + 9 个测试断言不减 |
> **像素门禁的已知噪声**：8 个面板里有 7 个含直播动态内容（在线人数、榜单、抽奖条目、弹幕历史），同一天两次采集的像素差就有 0.7%–12.5%；因此像素门禁只在**静态内容面板**上单独成立（签到面板实测 0），其余面板以**结构化比对（几何/颜色/字体/顺序）**为主门禁。要上像素门禁的动态面板，必须先做"动态文本遮罩"。


**采集纪律**

- 视口 1625×763 / 1280×720 / 1024×576，DPR 1；每面板 4 态：展开 / 长内容滚动到底 / 空态 / 失败态；
- `page.evaluate` 里先注入冻结样式（动画与过渡置 none），并把数字类文本（在线人数、时间）替换成固定占位；
- 每轮打印注入包指纹（版本号 + 产物行数），避免旧 bundle 误判；
- 产物存 `docs/ui-migration/{baseline,after}/<panel>/`（`snapshot.json` / `*.png` / `diff.md`），路径写进提交信息，任何人可复跑复验。

## 7. 主题：只控插件 + Dock 右侧弧排三个小图标

### 7.1 位置与几何（已按你的否决重定：不退化、沿右侧弧形向下排）

现状几何（`ExPanel.css:31-50`、`:76-84`）：胶囊 `right:0` · 高 **76** · 圆角 **38** · `padding:10px 18px` · `overflow:visible`；关闭钮 × 在 `top:-9px right:-9px`（胶囊右上角外侧）。

三枚图标**沿胶囊右端半圆的弧内由上向下排**，弧半径 R=38：

| 枚 | 顺序 | 圆心角 θ | 相对弧心的 x | y |
|---|---|---|---|---|
| 1 | 白天 `sun` | +35° | 左移 **6.9px** | +21.8px |
| 2 | 黑夜 `moon-stars` | 0° | 0 | 0 |
| 3 | 跟随 `circle-half` | −35° | 左移 **6.9px** | −21.8px |

- 容器：`.ex-panel__theme` 绝对定位 `right:6px; top:50%; transform:translateY(-50%)`，`flex-direction:column`，每枚按上表加 `translateX` 偏置（形成弧而不是折线）。
- 图标 **18px**，间距 **2px**（三枚总高 58px；内容区 56px，靠胶囊 `overflow:visible` 兜 2px —— 出图后若你觉得贴边，我把 Dock 竖向 padding 10→8）。
- 选中态：图标填色 + **弧内侧 2px 竖条**（贴在胶囊边缘，沿用现有 Dock 选中语义，**不加白底**）。
- 命中区 **26×26**（`::after` 圆形撑开）：弧上间距 21.8px，做 44 会互相重叠 —— 这一条属"知情接受"（三枚是同一组单选，误触代价低）。**若你要求必须 44**：三枚改为竖排直列 gap 8（总高 70px，靠 overflow 溢出胶囊），我不擅自改。
- 必须由 `ExUI.themeSwitch()` 产出（C4），样式写 `ExPanel.css`。

### 7.2 作用域（只切插件自己）

- 判据写在插件根节点：`html[data-dx-theme="dark"]`，选择器**只命中插件自己的节点**（`.ex-panel`、`.miuix-modal`、三级面板容器、`.ChatToolBar-DanmakuTail`）。
- **不写 cookie**、**不派发 `StorageEvent`**、**不改宿主页面主题**；`auto` 只**读** `html[data-mantine-color-scheme]` 判断（只读不写）。
- 「同时把斗鱼切深」：**已否决，不实现**。
- 存储：`ExSave_theme` ∈ `light | dark | auto`，默认 `auto`。

### 7.3 取值（沿用定版 D2）

外壳 `rgba(16,20,26,0.18)` + `blur(30px) saturate(130%) brightness(0.45)`；卡片 `rgba(16,20,26,0.14)`；墨 `#ffffff / #e2e8f0 / #cbd5e1`；图形 `#7db0ff`；输入框 `rgba(255,255,255,0.08)`；分割线 `rgba(255,255,255,0.10)`；开关轨道由黑 14% 反转为白 22%（造型不动）。

### 7.4 宽度预算（真机实测，2026-11-01）

- 磁贴：8 枚 × **56×56**，间距 **66px**（1625 档首枚 x=708、末枚右缘 x=1226）。
- **第二份容器**：存在一份**全零尺寸**的 `.ex-panel__wrap`（浮动宿主那份）；量尺寸必须取有尺寸那份，否则量到 0。

**三档视口实测（2026-11-01，同一构建）**

| 视口 | 胶囊 rect | 右缘到视口右边界 | 面板 |
|---|---|---|---|
| 1625 × 763 | [689, 575, **556**, 76] | **380px** | 380×370 |
| 1280 × 720 | [344, 532, **556**, 76] | **380px** | 380×370 |
| 1024 × 576 | [73, 388, **556**, 76] | **395px** | 380×370 |

结论：**胶囊宽度三档恒定 556**（8 枚磁贴固定），它的 x 随所在容器浮动，**从不贴视口右缘** —— 所以"1024 放不下"这个担忧在实测里不成立：三档都留了 380–395px 的右侧余量。三枚 18px 图标 + 弧偏置 ≈ **62px**，直接吃这段余量，**不需要为它压缩磁贴间距、更不需要退化成单图标**。

仍需在 S5 出图时目视确认的一条：图标挂在胶囊**右端弧内**，与关闭钮 ×（`top:-9 right:-9`，胶囊外右上角）的视觉间距。这一条看图定，不由算术定。

放不下时的兜底顺序：① 收紧磁贴间距 → ② 图标降 16px、间距 4 → ③ ~~退化为单图标循环~~（**已被你否决，不再作为候选**）。
