## 五条路线：默认 G2，另有 G / G3 / D / B

| 参数 | 路线 | 样式表 | 透光率 / 特征 |
| --- | --- | --- | --- |
| `?skin=glass2`（**默认**） | G2 · 单层玻璃卡 | `after-glass2.css` | 38%（卡片 0.62） |
| `?skin=dark` | **D · 深色玻璃** | `after-dark.css` | 整套转深色，卡片 0.70 + 白字（最坏帧 6.83） |
| `?skin=dark2` | **D2 · 深色薄玻璃** | `after-dark2.css` | 整套转深色，卡片 tint 0.14 + brightness 归一化，**透光 70%**（最坏帧 7.35） |
| `?skin=glass` | G · 玻璃托盘 + 内容岛 | `after-glass.css` | 13%（卡片 0.87） |
| `?skin=glass3` | G3 · 玻璃卡 + 文字托 | `after-glass3.css` | ≈80%（卡片 0.16） |
| `?skin=card` | B · 磨砂白卡（备查） | `after.css` | — |

**D 的代价**：整套转深色，与斗鱼亮色页面割裂 —— 面板是深色玻璃，聊天区与播放器工具条仍是浅色，交界处会出现硬接缝。

**D 与 D2 的区别**：D 只靠 alpha 0.70 压暗，玻璃越实才越读得清（用户判「不够透」）；D2 把压暗交给 `brightness(0.45)`，面薄到 tint 0.14，透光 70%。
**D2 的 filter 结构**：`after-dark2.css` 里**只有面板外壳与 Dock 胶囊**带 `backdrop-filter`，卡片 / 头部 / 选项行 / 磁贴一律 `none` + 只叠 `rgba(16,20,26,0.14)`。
grep 计数：`backdrop-filter` 共 12 行 = **4 行真滤镜**（2 处声明 × 2 家厂商）+ 8 行显式 `none`（用来压掉源码里卡片上的 `blur(12px)`）。同屏 filter 层从 10 层降到 2 层。

**1024 宽下的 9 磁贴**：胶囊 602px、所在工具条区域 952px —— **放得下，但贴死右边**（右间隙 0px，源码 `right: 0`），页面无横向滚动。`shots/57-dock-9tiles-1024.png`。

四条路线互斥：harness 用 `<link data-skin>` 的 media 开关切换，同一时刻只生效一张。
**越透代价越大**：G2 的次级文字只能到 `#1e293b`、蓝必须打包成药丸；G3 每块文字都要带「托」。三档并排见 `shots/34-tiers.png`。

## 为什么玻璃路线必须是「托盘 + 岛」（三条算术事实）

1. 白玻璃只有 alpha ≤0.45 才叫「能看见后面」；而 alpha 0.42 时 `#0f172a` 在纯黑帧上只有 **3.35:1**、`#334155` 只有 **1.94:1**
   —— **任何深墨文字压在真玻璃上都读不了**，全玻璃 + 文字这条路走不通。
2. 深玻璃 `rgba(16,20,26,0.70)` + 白字在纯黑 / 暗帧 / 亮帧 / 纯白四种帧上都过（**6.83–19.3**），但那是整体转深色，用户不要。
3. 所以唯一「既是玻璃、又有文字」的结构是：**玻璃只做外壳，文字永远坐在自己的实心岛上**（macOS 26 / iOS 控制中心同款）。

## 已知边界（不要当成已验收）

1. **只覆盖 6 行**：Dock + 扩展功能 / 版本更新 / 直播间工具 / 一键签到 + 控件台。其余四个三级面板（弹幕小助手 / 全站抽奖 / 一键续牌 / 同屏播放）没做 after 侧。
2. **z-index 只出表不改值**：13 档 → 5 档的目标刻度写在 `after.css` A14 注释与差分表里；覆盖层里压小它可能让面板沉到播放器下面，必须回 src 改并真机复验。
3. **真帧只有两档亮度**：暗 82/255、亮 145/255，都不算极端；极限亮与纯黑只在差分表的合成模型里覆盖。
4. **悬停态是镜像出来的**：静态截图没法把鼠标同时停在两列上，`.is-demo-hover` 的 5 条声明逐字抄自源码，没加任何改良。
5. **粘底操作条是设计**：用户 2026-11-01 确认，两条路线都不动 `position: sticky`，也不动 `common.js:592` 的 `ExUI_stickActionBar`。
6. **图标配色那条已降级**：真机 CDP 复核证明常态/选中规则都命中生效、像素取样 `#324054` / `#0065fd`，「选中态被染成橙色」的结论已撤回；路线 G 另从「磁贴图形对比只有 1.94:1」入手改图标墨色，那是另一个问题。
7. **2× 放大图用 CSS `zoom: 2`**（不是 `transform: scale`），文字按 2× 字号重新栅格化，所以不糊。
