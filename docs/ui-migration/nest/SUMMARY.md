# S0.5 关层实验 · 结论表（检查点①）

> 方法：在真机 DOM 上**逐层剥离**（改名让该层的 CSS 全部失效），每次剥离后测量，再恢复。
> 命令：`ego-browser nodejs < tools/ui-nest-probe.mjs` → `node tools/ui-nest-report.mjs`
> 原始数据：本目录 `<panel>/<mode>.json` + `<mode>-1625.png`；指标表见 `_metrics.md`。
> 采样：1625×763 · 8 面板 × 5 模式（base / noBody / noShell / noCard / all）= 40 份快照。

## 三层各自的承重结论

| 层 | 剥离对象 | 8 面板实测 | 判定 |
|---|---|---|---|
| **L-B 外壳** | 根节点 `miuix-modal` 类 + 注入的标题栏 | **位移 0 / 颜色变化 0（8/8 面板全部为 0）** | **纯外观壳**：拆掉不影响任何子元素几何与配色 → 可由 ExUI 直接替换，风险最低 |
| **L-A 内容区** | `.miuix-modal__body` | 8/8 面板都发生位移，最大位移 extool **892px**、exupdate **973px**、livetool 228px、bloop 224px、sign 211px、fans-continue 159px、exlottery 72px、popup 58px | **承重结构**：它是"固定 370 高 + 内容滚动 + 内边距"的那一层，拆了内容整体上窜到几百 px → **必须由 ExUI 等价重建** |
| **L-C 卡片/子项** | `fans-panel__card` / `popup-panel__card` / `sign-option-item` / `bloop__param_item` / `livetool__cell` | 位移 126–336px；**文本裸压玻璃**（无实底祖先）extool **48 处**、sign 17、exupdate 17、bloop 15、livetool 12、fans-continue 6、exlottery 5、popup 3 | **文字地基层**：拆掉后文字直接压在模糊上，对比度崩 → 必须由 `.ui-card` / `.ui-row` 承接，且**先有 S4 的墨色定值**才有意义 |

## 对 ExUI 契约的直接输入

1. **外壳（L-B）不需要复刻任何东西**：ExUI 只要产出同样的 `.miuix-modal` 根 + 标题栏结构即可，内部布局与它无关。
2. **内容区（L-A）必须原样保留语义**：固定高 370、`overflow` 滚动、内边距 —— 这三件事在 ExUI 的 `.ui-card` 外层必须存在，且"卡片高度由内容决定、由 body 滚动"（§1.5 那条硬判据）。
3. **卡片/子项（L-C）不是纯装饰**：它同时承担**文本底色**。所以 S4（墨色）如果放在迁移之后，中间会有一段"文字直接压在玻璃上"的状态 —— 结论：**S2 迁移期间必须保留卡片层的实底，不能提前拆**。
4. **同屏播放多出来的 `.popup-panel__page` 是正面设计**（吸收 848px 位移差）：它应该被写进契约，而不是当成"多余的一层"删掉。

## 结论一句话

**三层里只有外壳层可以随便换；内容区和卡片层是承重的，必须等价重建。** 上一轮把三层连同观感一起推翻，等于同时拆了承重墙和墙纸。
