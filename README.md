## 【版本说明】

### 一、 🛠️ 底层重构
1. **⚡ 全链路协议级画质截杀**：废除原版事后 DOM 模拟点击，重构为原生主上下文低清预载流截杀与 `/betard/{rid}` 响应嗅探改写，源头掐死二次重连。
2. **🧹 XHR 拦截弱引用重构**：全局网络缓存由强引用 Map 全面换装为 WeakMap，无引用请求自动被 V8 垃圾回收，彻底根除挂机内存暴涨。
3. **🛡️ WebRTC 规范状态机重构**：弃用原版粗暴的空函数，封装工业级 GracefulP2PBlocker 类，优雅拒绝 P2P，兼顾 100% 阻断偷跑与零控制台报错。
4. **🔌 榜单计算引擎主上下文解耦**：拆除尾部已失效的旧版 STT 逻辑，重构为独立主上下文极速注入的高性能计算管线。

---

### 二、 🚀 功能优化
1. **🎬 秒开流畅度质变飞跃**：彻底消灭点进房间先播低清、数秒后突发黑屏卡顿切流的顽疾，实现首帧直接原画秒开。
2. **🏆 全面换装新版榜单贡献值系统**：针对原版因前端重构已彻底失效、长期空白的严重问题，换装新版引擎，完美恢复日/周/月/总榜真实亲密度贡献值，并支持与暗色主题自动同色。
3. **🎚️ 滚轮调音 I/O 防抖优化**：滑动调音加入 300ms 写入防抖，彻底消除高频同步写磁盘造成的界面掉帧。
4. **🍃 彻底纯净化与去商业化**：物理剔除原版强插的商业推广（FKBUFF 饰品议价及 Base64 推广图）、外部商业代抢引流链接（星推荐代抢），拔除后台百度统计代码与追踪标签。

---

### 三、 🐛 Bug 修复
1. **💥 修复独立流弹窗崩溃**：修正 `rn(s, e)` 模板字符串遗留的 `String(id)` 变量未定义 Bug，彻底解决严格模式闪退。
2. **🔄 修复弹幕助手删除反转**：将反向过滤 `xe.filter(e => e === t)` 纠正为 `e !== t`，修复删单条反把其余全删光的重大逻辑缺陷。
3. **⚠️ 修复严格模式全局污染**：补全一键续牌局部 `var count`，解耦进场欢迎隐式全局变量 `reply`，消除严格模式中断。
4. **🧱 修复 DOM 原型链规范破坏**：拦截脚本注入时规范补齐原节点返回 `return e`，杜绝返回空碎片导致的现代前端空指针崩溃。
5. **🌐 兼容现代 Chrome 115+**：对已废弃的 `document.domain = "douyu.com"` 增加安全隔离保护，消除新版浏览器异常。
6. **📝 修复语法隐蔽报错**：重构 `else` 分支逗号连接 `try-catch` 导致的引擎级 `SyntaxError` 语法错误。

---

### 四、 ✨ 新增功能
1. **⏱️ 12 秒起播黄金保护窗（isInitialLoad 状态机）**：开播前 12 秒强锁最高画质保证无缝秒开；12 秒后透明放行手动切流畅/高清，网络卡顿绝不锁死。
2. **🔄 SPA 换房自感知重置**：实时感知单页路由 `location.pathname`，站内无刷新点击切换其他主播时，自动重启 12 秒黄金保护期。
3. **🔍 动态哈希 DOM 结构探测**：新版榜单引擎具备结构探测与容灾机制，全面兼容斗鱼新版混淆类名，即使官方频繁构建也能精准挂载。
