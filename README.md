# DouyuEx-RL (Reborn Lite)

斗鱼网页端增强用户脚本，提供播放控制、多房间同屏、弹幕工具和日常任务等功能。

本项目由社区维护，在[原版 DouyuEx](https://github.com/qianjiachun/douyuEx) 的未混淆源码上继续开发。原作者小淳于 2026 年 8 月宣布停更。感谢原作者及贡献者的工作；本项目与斗鱼官方无关。

[安装脚本](https://greasyfork.org/zh-CN/scripts/595575-douyuex-rl-%E6%96%97%E9%B1%BC%E7%9B%B4%E6%92%AD%E9%97%B4%E5%A2%9E%E5%BC%BA%E6%8F%92%E4%BB%B6-reborn-lite) · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/xayahcore/DouyuEx-RL/issues)

## 安装与使用

1. 在 Chrome 或 Edge 中安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 在扩展详情中允许 Tampermonkey 执行用户脚本。Chrome 138+ 可打开 **Allow User Scripts／允许用户脚本**；其他适用版本可启用开发者模式，具体见 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)。
3. 打开上方 Greasy Fork 安装页，点击安装，并在油猴确认页完成安装。
4. 刷新斗鱼直播间，通过精灵球图标打开工具条，按需启用功能。签到、领取任务和账号相关功能需要登录斗鱼。

增强画中画等功能需要浏览器支持相应 API。P2P、防页签冻结等设置提示刷新时，请刷新直播间使修改生效。更新可通过油猴检查，或打开脚本的「版本更新」面板查看。

### 从原版或其他维护版切换

先在油猴管理面板导出旧脚本，并记录重要设置。设置分别保存在斗鱼站点的 localStorage 和油猴脚本存储中，单独导出脚本代码并不包含全部配置；同一浏览器可能沿用部分站点设置，其他设置需要重新配置。

切换后只启用一个 DouyuEx 版本，再刷新直播间。原版、RL 正式版和 NEXT 测试版同时运行，可能重复绑定事件、发起任务或修改播放器。首次使用时检查签到选项、送礼设置以及钓鱼和红包开关，再开启需要的任务。

## 主要功能

| 分类 | 功能 |
| --- | --- |
| 播放控制 | 自动最高画质、网页全屏、滤镜、倍速、画面缩放、截图与 GIF、直播流地址复制、原生及增强画中画 |
| 多房间观看 | 最多 5 个斗鱼直播间同屏、拖拽换位、独立音量与画质设置、外房弹幕合并 |
| 弹幕与直播间工具 | 进场提示与重复弹幕屏蔽、弹幕背景开关、收藏、小尾巴、发送回执检测、投票、关键词回复与禁言、自动谢礼物 |
| 日常任务 | 按项签到、看播积分领取、等级任务、粉丝牌明细与一键续牌、自动钓鱼、礼物红包、半自动宝箱 |
| 页面与账号 | 广告及推广元素隐藏、排行榜贡献值、开播与本人观看时间、背包信息、账号切换、P2P 阻断与页面防自动暂停设置 |

自动最高画质根据可用档位自动选择，服务端权限限制仍适用。任务是否可执行取决于登录状态、房间和活动规则；禁言等操作还需要相应的房间权限。

## 功能边界与外部服务

- `doseeing.com` 数据源停服后，依赖它的「在看直播」统计条已移除。历史弹幕查询目前不可用，保留的入口会提示数据源停服；本地弹幕收藏是独立功能。
- 「扩展功能 → 在线工具」仍保留打开 `douyuex.com` 的按钮。它会跳转第三方网站，该站的可用性不由本脚本控制。
- 已下线的房间／粉丝牌签到和钻粉联赛签到项已移除。旧版的虎牙、B 站及 iframe 单窗播放入口也已移除，当前同屏播放针对斗鱼直播间。
- 防页签冻结会调整页面可见性行为，但后台播放仍受浏览器节能策略影响。多屏、录制、画中画和自动任务会增加资源占用。

脚本在浏览器中运行，会按功能请求斗鱼接口、从 CDN 加载依赖，并访问 GitHub 或 Greasy Fork 等更新来源。网络权限见 [src/main.js](src/main.js) 中的脚本元数据。

## 性能说明

部分网络任务按顺序执行并限制失败重试，音量设置保存使用防抖，XHR 请求体通过 WeakMap 关联。这些改动针对重复请求、频繁写入和对象引用保留。实际 CPU、内存、带宽和起播时间仍取决于房间弹幕量、开启的功能、浏览器及网络环境，需要通过测量判断。

比较版本时，请使用相同直播间、画质和功能设置，分别记录前台播放、后台播放及长时间运行的结果。反馈性能问题时附上测量条件和 Performance 记录，便于复现。

## 本地开发

使用 Node.js 24 和 npm，在仓库根目录执行：

```bash
npm ci
npm run build
npm test
```

构建生成根目录的 `DouyuEx_RL.user.js`，以及 `dist/` 中的展开版、压缩版和版本文件。修改 `src/` 后重新构建，不要直接修改生成的脚本。测试脚本以 [package.json](package.json) 为准。

构建会检查 CSS 嵌入、版本更新日志和 JavaScript 语法；`vm.Script` 的语法检查不验证浏览器 API 或线上接口是否可用。涉及播放器、页面结构或账号操作的改动还需要在真实浏览器中验证。仓库目前没有 CI，构建和测试需由维护者执行。

```text
src/
├── core/       # 画质与排行榜等核心逻辑
├── packages/   # 按功能组织的页面组件与业务代码
├── require/    # Hook、协议、WebSocket 等公共代码
├── routers/    # 页面入口与初始化
├── common.js   # 公共函数与运行状态
└── main.js     # 用户脚本元数据、模块接线与样式入口
tests/          # 源码及构建产物的回归测试
docs/           # 维护资料与截图
build.js        # 拼接、检查与压缩脚本
```

大改动和待实机验收的功能在 `DYEXRL-NEXT` 分支维护；`preview` 是发布基线，`main` 用于正式发布。提交前运行构建和测试，发布合并后在 `main` 上重新验证。分支、版本和发版约定见 [AGENTS.md](AGENTS.md)。

## 反馈与贡献

提交 [Issue](https://github.com/xayahcore/DouyuEx-RL/issues) 时，请提供：

- 浏览器、Tampermonkey 和脚本版本，以及使用正式版还是 NEXT。
- 房间链接、是否登录、开启了哪些相关功能，是否同时运行其他斗鱼脚本。
- 复现步骤、预期与实际结果；有条件时附截图和相关控制台错误。
- 性能问题的画质、同屏房间数、前后台状态和运行时长。

分享日志前请移除 Cookie、令牌和账号信息。贡献代码时说明问题、改动及验证结果；历史更新统一记录在 [CHANGELOG.md](CHANGELOG.md)，许可证信息见 [package.json](package.json)。
